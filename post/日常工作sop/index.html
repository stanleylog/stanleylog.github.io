日常工作SOP

Written by Stanley Sun on 2026-11-12 in 个人分享

自从不上班开始，自己开始有精力重新的重组自己的工作流程。之前的模式基本以日历、待办为驱动的方式。 现在在此之上加入了大量工作笔记的内容，SOP虽还未定型，但较之前已经有了很多好的体验。

                     
        +----------+ 
        |  定目标   | 
        +----+-----+ 
             |       
        +----v-----+ 
  +---->+  排任务   | 
  |     +----------+ 
  |          |       
  |     +----v-----+ 
  |     |  做执行   | 
  |     +----+-----+ 
  |          |       
  |     +----v-----+ 
  +-----+  做复盘   | 
        +----------+

第一步 定目标

首先经过思维导图的方式分析后续的工作方向，细化到需要完成的粗颗粒度事项。

第二步 排任务

对粗颗粒度任务进行细化，通过日历、待办的形式进行下发管理。 这个环境就可以加入时间上的约束了。

第三步 做执行

根据日历、待办每日创建工作记录文档， 我这里使用的obsidian。 工作记录分为如下几个部分：

  • 任务： 这里的任务应该是今天需要完成的任务， 如果是跨天任务需要进行细化。

  • 思考：在本日碰到的新想法、感悟进行记录。

  • 逾期待办：delay的任务，需要尽快完成。

第四部 做复盘

每周创建周记复盘文档， 分为两块主题：

  • 事项：提炼本周完成的任务，这里的任务应该是粗颗粒度的，太细的话就变成流水账了，就失去意义了。

  • 反思：对本周工作做整体性的总结，纠正偏差。安排下一周工作方向及排期。
